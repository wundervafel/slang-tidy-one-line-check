Конфиг для проверки чекера - tidy-config в корне проекта.

Исходный код чекера - slang/tools/tidy/src/style/NoOneLineMultiAssign.cpp

Тест для проверки работы чекера - test.sv в корне проекта

Известные проблемы:
- Если Case стоит первым в теле блока, считается что блок начинается на той же строчке, что и Case.
- initial, always и always_ff не считаются частью выражения.
- Все циклы, инициализации в начале циклов и выражения, написанные на одной строчке с условиями цикла, считаются написанными на одной строчке с выражениями.

Конфиг для проверки чекера - tidy-config в корне проекта.

Исходный код чекера - slang/tools/tidy/src/style/NoOneLineMultiAssign.cpp

Тест для проверки работы чекера - test.sv в корне проекта

Известные проблемы:
- Некоторые локации внутри макросов не раскрываются корректно, поэтому диагностика указывает только на место вызова макроса, но не на место внутри макроса.
- Ключевое слово assign, используемое при некоторых присваиваниях вне блоков, корректно не распознается чекером, поэтому диагностика не может распознать, находится ли оно на одной строке с другими выражениями.
- Чекер никак не рассматривает объявления и завершения модулей и некоторые другие конструкции языка.
